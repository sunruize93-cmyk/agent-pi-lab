# 首期联合试点

状态：`proposed`。本文是待确认的执行协议，不表示实验已启动或资源已落实。

## 唯一任务

在一个真实使用的开源计算研究工作流中，提高科研 agent 的有效实验产出，减少错误度量、单次偶然结果、证据缺失或失败恢复引起的无效消耗，同时保持结论可复核。

公开候选信号包括 autoresearch 的 [Issue 651](https://github.com/karpathy/autoresearch/issues/651) 与 [Issue 599](https://github.com/karpathy/autoresearch/issues/599)。它们是使用者报告，不是本社区已复现的缺陷、维护者合作承诺或新方法证据。

## 启动门槛

前两周完成以下条件，否则暂停：

- 至少一个实际使用方确认问题、部署约束和验收方式。
- 确认研究者、PI 对照、独立复核人和运营的可用工时、费用与职责。
- 资源提供方确认实际可使用的额度、权限和期限。
- 冻结仓库提交、数据标识、环境、硬件、评价脚本、四个外部验收问题和成本口径。
- 用小规模校验确认任务可运行、许可允许、预算可覆盖；检查成本计入首期预算。

如果经典做法已经稳定满足具体需求，记录结果，停止该子问题。没有真实使用方就不临时造题维持项目。

## Agent 的研究空间

Agent PI 可在共同目标内选择子问题和解释，决定实验、人员分工、证据要求及止损。可探索重复实验和停止规则、度量与产物一致性、失败诊断和恢复等路线。经典方法可以成为有效交付，但不得包装为算法创新。

原目标、规格与评价不能被弱化。两组都获得重复种子、置信区间、完整日志、检查点、独立复跑和已有工具。不得把一组有权使用的工具或精度恢复能力从另一组删除。

## 同信息同预算对照

四个外部问题各做一次 Agent PI 运行和一次人类 PI 运行，共八次。每次的起始材料、可访问资料、模型与工具、专家能力范围一致；人类 PI 可看到相同 AI 助手提出的候选方案。行动导致不同的后续信息属于比较的一部分。

每次运行上限：总成本 10,000 元，研究者 20 小时，API 与云计算合计 1,000 元。人类 PI 最多 8 小时；agent 组的人工科学救场按同一 PI 费率计入。未用的管理额度不得换成额外研究者工时或算力。

研究者跨不同问题平衡分组，同一人不处理同一问题的两组版本。各组结果封存后再交换；记录不可避免的信息泄漏。独立复核尽可能去除组别标识，并报告盲法局限。

## 交付

- 冻结的实验包，含代码和数据标识、运行指令、配置、原始结果及所有失败记录。
- 四组配对任务及全部八次运行的决策、工时和费用台账。
- 独立复核报告与至少一项满足使用方事前条件的交付；采纳、合并与公开状态分开报告。
- 是否继续的结论。首期不以新算法、投稿数量或录用为必需结果。
