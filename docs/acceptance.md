# 验收与止损

以下数值是拟议的试点门槛，须在运行前确认。四组配对任务用于可行性判断，不支持跨领域优越性或统计显著性的结论。

## 拟议扩期门槛

| 维度 | 条件 |
| --- | --- |
| 科学质量 | Agent 组至少 3/4 工作包通过独立复核，数量不低于人类 PI 组；没有未纠正的重大结论或数据完整性错误。符合原条件的负结果可以通过。 |
| 总成本 | 全部运行成本 / 合格工作包数量，agent 组目标比人类 PI 组降低至少 15%。失败和重试不能移出分子。 |
| 自主程度 | 每个 agent 工作包固定五个关键节点，共 20 个；至少 16 个未被人类实质改写。额外变更另记，不扩大分母。 |
| 人工依赖 | Agent 组科学救场合计不超过 8 小时，按同一 PI 费率计费。行政时间另记但仍计入总成本。 |
| 参与体验 | 至少 3/4 研究协作者愿意在相同条件下再参与一期；保留退出和不同意的原因。 |
| 可用性 | 所有八次运行有完整台账和复核；至少一项交付满足使用方事前条件。关键结论能追溯到代码、数据和原始结果。 |

五个固定节点：子问题与解释、取证计划、分工与预算、路线复审、结论与交付。人类提供实质方案即算介入，不能因为 agent 随后复述就记为自主。

## 成本如何分摊

按任务事前确定同一口径，分摊准备、运营、发起协调与独立复核成本，并同时披露未分摊的直接成本。资源赞助与志愿工时按一致的替代成本计入比较，不当作免费优势。保留数量、币种、换算依据与实际使用量。

任一组没有合格交付时，不计算成本优势；同时报告花费、失败和质量，不能用删去失败任务修复比率。所有工作包以冻结的外部问题为单位，不拆碎任务增加计数。

## 结果如何表述

- 质量与全部扩期门槛通过：可以申请下一阶段资源，不代表已经证明广泛优越性。
- 质量通过但效率未通过：只报告可运行，不能宣传优于人类 PI。
- 强基线稳定解决：记录并停止方法创新主张；独立评估工程与组织价值。
- 需求、证据、预算或许可未通过：暂停新增执行并如实报告。

不得因没有正结果而隐去任务、拖延报告或更改门槛。扩期需要明确资源支持，不能仅为追求好看的结果延长。
