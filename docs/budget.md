# 首期预算

状态：`proposed`，币种：人民币。人数、费率和额度是项目规划假设，不是市场报价、已确认薪酬或已获资助。

| 项目 | 假设 | 8 周金额 元 |
| --- | --- | ---: |
| 研究协作者 | 4 人 × 48 小时 × 250 元；平均每周 6 小时 | 48,000 |
| 人类 PI 强基线 | 32 小时 × 500 元 | 16,000 |
| 独立复核 | 2 人合计 32 小时 × 300 元 | 9,600 |
| 运营 | 48 小时 × 150 元 | 7,200 |
| 发起协调 | 24 小时 × 150 元 | 3,600 |
| 模型 API | 包括 PI、研究者、复核及失败重试 | 8,000 |
| 云计算 | 包括准备、比较和独立复跑 | 6,000 |
| 存储及必要管理 | 实际核销 | 1,600 |
| 预计基础支出 | 不含预备金 | **100,000** |
| 预备金 | 人工救场、服务变化与必要重跑 | **12,000** |
| 基础期总上限 | 现金与可核销资源支持合计 | **112,000** |

研究者 192 小时中，32 小时用于共同准备，其余 160 小时用于八次运行。八次模型与云计算每次上限 1,000 元，共 8,000 元；另有 6,000 元用于准备与独立复核。Agent 组科学救场按每小时 500 元计入预备金及对应任务上限，不重复记账。

## 有条件扩期

第 9–12 周追加：研究协作者 24,000；PI 对照 4,000；复核 2,400；运营 2,400；发起协调 1,200；API 2,000；云计算 2,000。共 **38,000 元**，累计上限 **150,000 元**。

只有第 8 周达到事前门槛并获得资源方确认后才启动。不能以未完成的投稿或不理想的结果为理由自动延长。

## 资金释放与记账

建议分三笔：启动 25,000；第 2 周需求与资源检查通过后 45,000；第 5 周执行检查通过后 42,000。后续款不以正结果为条件。停止时核销已发生费用，余额按正式合作约定退回或重新约定用途。

首期没有收款链接。收到资源前明确责任接收方、用途、核销、许可和退出安排。实物额度按实际可用、实际使用和可替代支出核算；未使用的宣传面值不计支出。

模型、实例、汇率和税费在启动前按实际条件核对：[Claude API 定价](https://platform.claude.com/docs/en/about-claude/pricing)、[Modal 云计算定价](https://modal.com/pricing)。不固定所谓永远最强模型，也不承诺免费供应商额度。

预算不含基金会注册、全职岗位、实体实验室、基础模型训练、差旅或会议注册；这些如有需要另行立项。

机器可读数值在 [budget.json](budget.json)，空白台账在 [cost-ledger.csv](../templates/cost-ledger.csv)。运行 `python3 scripts/check_community.py` 可检查总额和资源口径；不代表费用已发生或结论已验证。
