# 资源支持与赞助

社区正在筹备首期联合试点。欢迎表达意向；目前不收取参与费，不提供收款链接，也未确认任何赞助或机构合作。

## 可以支持什么

- 研究者津贴：基础期拟议预算 48,000 元。
- API 和云计算：基础期合计预算上限 14,000 元，需确认实际可用期限与条款。
- 独立复核：基础期预算 9,600 元。
- 真实任务、验证环境与使用方验收：先确认范围、授权和可投入时间。
- 运营或发起协调：全成本中列示，不隐去实际人类支持。

基础期全成本上限 112,000 元，可由多方的现金和可核销资源联合支持。完整 [预算](budget.md) 与 [验收](acceptance.md) 对所有参与方适用。

## 资源方得到什么

阶段性进度与成本报告、经许可公开的实验包和失败记录、署名致谢，以及一次结果交流。若需要非公开材料、品牌展示或额外评估，先约定范围；不自动包含在赞助中。

赞助不能购买正结果、论文作者资格、结论否决权或相对于强基线的额外信息优势。发布前可以核对事实、许可和敏感信息，不因负结果阻止报告。

## 如何开始

使用 [赞助意向表单](https://github.com/sunruize93-cmyk/agent-pi-lab/issues/new?template=sponsorship.yml)，只写可以公开的资源类别、范围和约束。不要贴合同、账单、账户或个人联系方式；需要私下沟通时先约定渠道。

Issue 中的意向不算到账，也不授予机构名称和 Logo 的使用权。实际支持前明确资源接收方、双方责任、用途、计费、核销和停止后的余额处理。没有书面确认前，不把提出意向的组织写成合作伙伴。

本项目尚未注册基金会，不提供税收抵扣、投资回报或论文录用承诺。
